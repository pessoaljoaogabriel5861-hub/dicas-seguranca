# 🛒 Compra Segura Digital

## Segurança nas compras online para idosos

O **Compra Segura Digital** é um website desenvolvido como projeto de Trabalho de Conclusão de Curso (TCC), com o objetivo de promover **informação, prevenção e segurança** para pessoas idosas durante a realização de compras pela internet.

O projeto aborda os principais riscos relacionados às compras online e apresenta orientações para ajudar o público idoso a reconhecer possíveis golpes digitais, identificar situações suspeitas e adotar práticas mais seguras no ambiente virtual.

---

## 🎯 Objetivo do projeto

Desenvolver um website educativo e acessível voltado à população idosa, oferecendo informações de fácil compreensão sobre segurança nas compras online e prevenção de golpes digitais.

O projeto busca contribuir para que os usuários tenham mais conhecimento e segurança ao utilizar lojas virtuais, realizar pagamentos e fornecer informações pessoais na internet.

---

## 👵 Público-alvo

O website é direcionado principalmente para:

- Pessoas idosas que realizam compras pela internet;
- Pessoas que estão começando a utilizar lojas virtuais;
- Familiares e pessoas que auxiliam idosos no uso da tecnologia;
- Usuários interessados em aprender sobre prevenção de golpes digitais.

---

## 🔐 Principais temas abordados

O projeto trabalha conteúdos relacionados a:

- Segurança nas compras online;
- Identificação de sites suspeitos;
- Ofertas e promoções fraudulentas;
- Proteção de dados pessoais;
- Segurança durante pagamentos;
- Phishing e mensagens falsas;
- Golpes relacionados a lojas virtuais;
- Cuidados antes de realizar uma compra;
- Importância de buscar ajuda em caso de dúvida.

---

## 💡 Proposta

O **Compra Segura Digital** utiliza uma abordagem educativa para apresentar informações de maneira simples, objetiva e acessível.

A proposta é transformar conceitos relacionados à segurança digital em orientações práticas que possam ser compreendidas e aplicadas no cotidiano.

Os principais pilares do projeto são:

**Informação • Prevenção • Segurança**

---

## 🌐 Website

O projeto consiste no desenvolvimento de um website com conteúdos educativos relacionados à segurança nas compras online.

A interface foi planejada considerando a necessidade de uma navegação simples e intuitiva, especialmente para usuários idosos.

Entre os elementos considerados no desenvolvimento estão:

- Organização clara das informações;
- Linguagem acessível;
- Elementos visuais relacionados à segurança digital;
- Navegação intuitiva;
- Conteúdo educativo;
- Orientações práticas para prevenção de golpes.

---

## 🛠️ Tecnologias utilizadas

As tecnologias utilizadas no desenvolvimento do projeto incluem:

- HTML5
- CSS3
- JavaScript

Essas tecnologias são utilizadas para estruturar, estilizar e adicionar funcionalidades e interatividade ao website.

## 📚 Projeto de TCC

**Tema:**

> Segurança nas compras online para idosos: desenvolvimento de um website para prevenção de golpes digitais.

O projeto foi desenvolvido com finalidade acadêmica, buscando aplicar conhecimentos relacionados ao desenvolvimento web e à segurança da informação em uma situação prática de conscientização digital.

---

## 🛡️ Importância do projeto

Com o crescimento das compras realizadas pela internet, torna-se cada vez mais importante conhecer os riscos existentes no ambiente digital.

O projeto busca contribuir para a conscientização do público idoso, incentivando práticas mais seguras e ajudando na identificação de possíveis tentativas de fraude.

A informação é uma das principais ferramentas para a prevenção de golpes digitais.
